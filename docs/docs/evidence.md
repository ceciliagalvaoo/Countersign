# Evidence

Transaction hashes prove the mechanism, not a market. Everything below is on the Stellar test network, with test assets that have no monetary value, except the mainnet slice (Table 10, limitation 14). Every hash links to stellar.expert, and every hash has a task and a decision-log line, except refusals that bypassed our server by design (Table 7) and setup transactions, which are marked "setup" and are not counted as evidence. The complete testnet export is `evidence/EVIDENCE.md` in the repository, generated by `npm --prefix tests run evidence`: 158 transactions; 37 of 37 agent purchases with `decision` equal to an APPROVED decision-log line; 36 on-chain refusals with no log line by design; 0 gaps; 0 divergences.

For an agent purchase, the first argument of `subscribe` is the `decision`. Open the link, read that argument, and compare it with the hash of the decision-log line shown in the table.
